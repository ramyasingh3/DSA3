# Target Sum Ways

## Problem
Assign +/- to reach target; count ways.

## Example
```
Input: [46, 24, 20, -10, -3, -10, 32, 42, -16, 45]
Output: (compute according to problem statement)
```

## Constraints
- Reasonable input sizes for interview settings (`n` up to ~10^5 unless noted)
- Aim for better than naive O(n^2) when possible

## Hint
Knapsack / subset-sum transform.

## Topic
Dynamic Programming
